Annotations

  1. [1] Description field: action line, not prose — The placeholder text shows the INT./EXT. format to immediately prime the correct input style. The helper text below the field reinforces this: "Action line only — no internal thought, no prose." This is a key craft constraint (BR-03) that the UI should actively teach. FR-20 BR-03
  2. [2] Dialogue snippet is optional and secondary — Placed after the description and clearly marked optional. The placeholder uses quotes to signal the expected format. A scene without dialogue is valid and common. FR-20
  3. [3] Act position as 4-way pill: Unplaced + Act 1/2/3 — "Not placed yet" is the default (dashed pill). This is not an error state — unplaced scenes are first-class. Clicking a pill selects it; clicking the selected pill deselects back to "Not placed yet." FR-20 FR-21
  4. [4] Promoted-from banner makes the source idea visible — When opened via "Promote to Scene" (FR-22), the modal shows the original What-If idea in a light banner at the top. This keeps the context visible while the user rewrites the description into proper action-line format. The modal title changes to "Promote to Scene" to signal the different entry path. FR-22
  5. [5] Pre-filled description from What-If — must be edited — The description textarea is pre-populated with the What-If content but highlighted as needing revision (helper text: "Edit into a proper action line"). The Save button is active immediately — user can save as-is if they choose — but the UI nudges toward proper format. FR-22
  6. [6] "Archive original" checkbox on promote flow — Lets the user clean up in one step: save the new scene and archive the source idea simultaneously. Unchecked by default — the original idea is kept unless explicitly dismissed. FR-13 FR-22
  7. [7] Delete scene is a danger-zone link, not a button — In edit mode, "Delete this scene…" appears below a divider in red. It's an underlined link, not a button — this reduces accidental taps. Clicking it should open a confirmation step before executing. Scene deletion is permanent (unlike idea archiving which is soft). Decision needed: should scene deletion be permanent or soft-archivable? The requirements don't specify.
