Annotations

  1. [1] Prev / Next navigation in breadcrumb — The breadcrumb bar includes ‹ › arrows to step through ideas in the current list context (whatever filter/sort was active when the user clicked in). This preserves the review flow — user can scan through stale ideas without returning to the list each time. FR-07
  2. [2] Stale banner is the primary review prompt — When lastReviewedAt is more than 14 days ago, a banner appears with the exact age and a "Mark as reviewed" link. Clicking "Mark as reviewed" updates lastReviewedAt and dismisses the banner without requiring any other action. FR-10 BR-04
  3. [3] Promote to Scene is surfaced as a dedicated icon button — The ↑ icon appears in the action row only for WHAT_IF type ideas (FR-22). For all other types it's hidden. This keeps it discoverable without cluttering the UI for non-promotable ideas. FR-22
  4. [4] Inline edit — click the content to edit — The idea content is not always in a textarea — it renders as plain text. Clicking it activates inline editing (textarea appears, Save/Cancel replace the action buttons). ⌘+Enter saves; Esc cancels. Saving also sets lastReviewedAt. FR-01
  5. [5] Tags are editable inline — Existing tags show an ✕ to remove. "+ add tag" opens a small inline text input. Tags are saved on blur or Enter. FR-04
  6. [6] Excitement widget is directly clickable in the sidebar — Clicking any dot sets the rating. Dot 1 = Low, 2 = Medium, 3 = High. Clicking the already-selected dot clears the rating (back to unset). Updating excitement also sets lastReviewedAt. FR-12
  7. [7] Project assignment via inline dropdown — The project selector in the sidebar is a dropdown. Selecting a project assigns the idea (FR-15). Selecting "— Unassigned —" removes the assignment. This replaces the "Assign to project" flow from the card action menu — same result, different entry point. FR-03 FR-15
  8. [8] Type is changeable from the sidebar — The type selector in the sidebar allows retyping an idea without going back to capture. This is how a raw/untyped idea gets classified. The "Set type now" link in the raw banner also scrolls to and activates this dropdown. FR-02 FR-11
  9. [9] Archive is in the sidebar danger zone, not a top-level action — Archiving is infrequent and irreversible in feel (even though it's soft). Placing it below a divider at the bottom of the sidebar reduces accidental activation while keeping it accessible. FR-13
