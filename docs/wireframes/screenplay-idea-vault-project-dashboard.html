Annotations

  1. [1] Ideas is the default tab — The dashboard opens on the Ideas tab. Ideas are shown in the same card format as the main vault, but scoped to this project only. No type sidebar here — filtering is lighter (search only), since the list is naturally smaller. FR-16
  2. [2] Status badge is editable via "Edit project" — The status (DEVELOPING / ACTIVE / SHELVED) is always visible in the header. Changing it is done through the "Edit project" action, which opens the Create/Edit Project Modal. No inline status toggle to keep the header clean. FR-14
  3. [3] Logline shown as prose — inline edit on click — The logline lives in the project header, always visible regardless of active tab. It's free-form text (FR-14). Clicking the logline text opens an inline edit (not a modal). When absent, it shows "No logline yet — add one" as a tap target. FR-14
  4. [4] Two CTAs on the Ideas tab: capture new vs. assign existing — "Capture new idea" opens the Quick Capture Modal pre-set to this project. "Assign existing idea" opens the drawer (State 5). The distinction is important — ideas often exist in the vault before a project forms around them. FR-15
  5. [5] Character cards in a grid, not a list — Characters have more structure than ideas (name + obsession + occupation), so a card grid reads better than rows. Each card surfaces the craft-critical fields — especially "Obsession" which is the character's driving want. FR-18 FR-19
  6. [6] "Obsession" field label is explicit — The label reads "Obsession (what drives them)" — not just "Obsession". This surfaces the screenplay craft principle directly in the UI, which is core to BR-03 (organized around craft frameworks, not generic note-taking). BR-03 FR-18
  7. [7] Act filter as pills above the scene list — Act 1/2/3 are pill filters. Counts shown per act. "Unplaced" scenes are always visible — scenes without an act assignment are valid and common early in development. The filter updates the list inline, no page reload. FR-21
  8. [8] Unplaced scenes use a dashed left border + dashed badge — Mirrors the raw/untyped pattern from the Ideas List: dashed visuals = incomplete, but not wrong. Unplaced scenes are first-class citizens in the scene bank. FR-20
  9. [9] Empty state offers both CTAs — A newly created project immediately offers "Capture new idea" and "Assign existing idea" side-by-side. This mirrors real usage — you often have ideas before you have a project name. BR-02
  10. [10] Assign ideas via a right-side drawer, not a modal — A slide-in drawer (rather than a full modal) lets the user see the project context while selecting ideas. The drawer shows only unassigned ideas and supports multi-select + search. The CTA label updates to reflect the count ("Assign 1 idea", "Assign 3 ideas"). FR-15
