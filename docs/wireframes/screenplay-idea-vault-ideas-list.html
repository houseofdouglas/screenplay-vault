Annotations

  1. [1] FAB is the persistent capture entry point — The + button appears in the top-right nav on every authenticated screen. Keyboard shortcut N also triggers the Quick Capture Modal. The nav is intentionally minimal — two items only (Ideas, Projects). FR-05
  2. [2] Type filter in sidebar, not a top bar — With 7 types plus "All", a sidebar list is cleaner than a horizontal pill row. Counts update in real-time as search/project filters are applied. Clicking a type sets it as the active filter. FR-09
  3. [3] Project filter in sidebar — Lists all the user's projects plus an "Unassigned" entry. Selecting a project narrows the idea list to only that project's ideas. This is a sidebar-level filter, not the same as the Project Dashboard view. FR-09
  4. [4] "Inbox" sidebar section for housekeeping views — "Stale ideas" (>14 days, FR-10) and "Raw / untyped" (FR-11) are shortcuts that pre-apply the relevant filter. "Archived" opens the archived ideas view. These are high-value housekeeping tasks surfaced without cluttering the main list. FR-10 FR-11 FR-13
  5. [5] Sort is a single dropdown, not a column header sort — Cards are not a table — sorting by column header doesn't apply. A simple dropdown with 3 options (Most recent, Type, Last reviewed) is sufficient. "Last reviewed" sort is the most powerful for surfacing stale ideas. FR-07
  6. [6] Stale indicator: date stamp, not just a dot — Showing the actual age ("21 days ago") is more actionable than a generic warning icon. The left border accent (solid gray) is a secondary visual cue. Cards older than 14 days since lastReviewedAt get this treatment. FR-10
  7. [7] Raw / untyped indicator: dashed border + dashed type badge — Ideas with no type assigned use a dashed left border and a dashed "UNTYPED" badge instead of a filled type pill. This is visually distinctive without being alarming — raw ideas are valid, just incomplete. FR-11
  8. [8] Active filter chips with "Clear all" — When filters are active, chips appear in the toolbar row. Each chip has an ✕ to remove that specific filter. "Clear all" resets everything. This maintains affordance for "how do I get back to all ideas?". FR-09
  9. [9] Empty state prompts the first action directly — The empty state is not just a message — it includes a primary CTA button (+ Capture an idea) and a keyboard shortcut reminder. No onboarding wizard, no multi-step setup — get straight to capture. BR-02
  10. [10] Card overflow menu for secondary actions — The ⋯ button on each card opens a context menu with: View/Edit, Assign to project, Promote to Scene (WHAT_IF type only), and Archive. Archive is visually separated and shown in red to signal destructive intent (even though it's soft/recoverable). FR-13 FR-22
  11. [11] Excitement rating: 3 dots, inline on card — Shown as 3 dots (filled = rated, dashed outline = not yet rated) on every card. The user can update the rating on the Idea Detail screen — it's read-only on the list card. This keeps the card compact while showing the data at a glance. FR-12
  12. [12] Search highlights matched text — When a search is active, matched terms are highlighted inline in the card content (light gray highlight). This is a quality-of-life feature — keeps the user oriented after filtering. FR-08
  13. [13] No-results state offers to capture the search term as a new idea — If a search returns nothing, the CTA is "Capture [term] as idea" — pre-filling the Quick Capture Modal with the search text. Turns a failed search into fast capture. BR-02
